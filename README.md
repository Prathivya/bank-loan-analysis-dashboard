Bank Loan Analysis Dashboard

An interactive Bank Loan Analysis Dashboard built using SQL, Power BI and Excel to analyze loan applications, funded amounts, repayments, interest rates and borrower trends.

Project Overview

This project focuses on analyzing bank loan data to identify trends in loan applications, funded amounts, repayments and borrower characteristics.

Tools & Technologies

SQL (MySQL),
Microsoft Power BI,
Microsoft Excel

Key Performance Indicators (KPIs)

Total Loan Applications,
Total Funded Amount,
Total Amount Received,
Average Interest Rate,
Average Debt-to-Income (DTI) Ratio

Dashboard Features

1. Overview Dashboard

Good Loan vs Bad Loan Analysis,
Monthly and Month-over-Month Analysis
Loan Applications and Funded Amount Trends,
State-wise Loan Distribution,
Loan Purpose Analysis

2. Details Dashboard

Detailed Loan Information,
Borrower and Loan Characteristics,
Interactive Filtering and Exploration

SQL Analysis

Summary and KPI Analysis,
MTD and PMTD Comparisons,
Good Loan and Bad Loan Analysis,
Loan Status Analysis,
Monthly Analysis,,
State-wise Analysis,
Term-wise Analysis,
Employee Length Analysis,
Loan Purpose Analysis,
Home Ownership Analysis,

Skills Demonstrated

SQL Querying and Data Analysis,
Data Cleaning,
KPI Development,
Data Visualization,
Interactive Dashboard Design,

Conclusion

The dashboard provides insights into loan performance, borrower profiles and lending trends to support data-driven decision-making.
